- 新增Docker可视化授权：独立桌面与受保护的管理入口，按账号暂停/恢复，候选会话验证后提交；超时、服务重启、未提交事务与迟到错误均有保护。容器与真实平台部署验收分开记录，见 [授权操作说明](AUTHORIZATION_OPERATIONS.md)。
- 数据与评论分开调度，支持错过每日时间后的补跑、失败延迟重试、任务超时和运行目录单实例锁。
- 健康检查区分身份、内容完整性、必要指标、评论及回复证据；记录实际运行结果并提供观察期门槛。
