# 登录失效提醒处理

含义：采集或会话检查确认平台登录失效、需要人工安全验证，或登录账号与绑定身份不一致，自动采集已暂停。临时网络错误和限流不属于此提醒。

先检查：打开邮件中的授权管理地址；远程回环地址先按 [Docker授权说明](../DOCKER_AUTHORIZATION.md) 建立SSH转发。选择邮件中的账号重新登录，点击“验证并保存”。官方令牌方式则更新凭证并重新验证。成功后自动解除本次告警，不发送额外恢复邮件。

仍未恢复：联系部署维护人员检查该账号配置和授权服务日志。检查调度器的 `last_session_results`、`run_history.jsonl` 及提醒任务的 `session_alert_cycle` 日志，可区分状态读取或发送失败。失败保留待发状态，不删除 `session_alert_state.json` 来清空告警，否则可能重复发信。
