## 会话与分页保护

当前实现直接打开正常作品管理页并点击网页“下一页”，只监听网页自行生成的图文已发布响应；不捕获或复用 token 请求头，不直接调用目录接口，不计算签名。账号设置响应中的证件、手机等私有字段不进入采集结果。可移植会话仅保存百度登录域的Cookies和本地状态，置于忽略入库的私有目录。

每页核验当前页码、每页条数、总条数及总页数；提前空页、短页、重复ID、总数变化、非已发布图文或作者不一致都会报告失败，保留旧快照。主动页数上限导致未完成时标记部分结果。遇登录失效、验证码或访问限制时停止，等待正常人工处理。

正式图文流水线、接入面板和只读验证均使用此后台适配器。旧公开列表仅保留格式兼容测试，默认流程不会退回缺少逐篇指标的公开列表。其它两个百家号按用户安排留到实际运行时独立授权，并各自核验身份与完整性。

百家号目前监测评论数量，不采集评论正文或回复关系。来源改变时静默重建数量基线，避免把口径变化误报为新评论。验证数据只写当前工作树 `.runtime/`；目标部署环境会话、剩余账号与七天观察仍需运行时验收。
